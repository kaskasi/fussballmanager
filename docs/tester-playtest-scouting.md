# Playtest checklist — discovery + Postfach (after save ≥ 61)

Run on a fresh or migrated save after buy-fix and scout Postfach ship.

1. **Pool growth:** Complete at least one region + one club scout from Netzwerk; Treffer fills without per-player map clicks.
2. **Postfach:** After week sim, open Post; scout completion card shows counts; **Verstanden** clears badge item; NEXT not blocked solely by this card.
3. **CTAs:** Region card → Netzwerk tab; club card → Treffer tab.
4. **Buy gate:** Non-pool player cannot complete purchase; message is understandable.
5. **Assman scouting (optional):** With delegation on, pool players get assigned over weeks without manual assign on each row.
6. **Loop compare:** Camp leader / training reminder still feel like stronger interrupts than map alone.
7. **Intake week:** Note whether intake remains the emotional peak.

Log the week you stop adding clubs — input for batch-scout UX (PRD 20).
